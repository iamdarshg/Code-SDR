## Root Cause of Non-Convergence

Power was originally distributed via overlapping full-board F.Cu zones that
carve holes in each other by priority, fragmenting GND. Removing them fixes
GND but strands power nets with no alternate path. Remaining opens are small
physical gaps that require obstacle-aware routing, which is not achievable by:
- Straight-line bridging (creates shorts across intervening copper)
- Same-layer zone re-addition (priority carving recurs)
- Freerouting batch mode (NPE crash on this geometry)

## Recommended Path Forward

1. Manual KiCad GUI routing of remaining opens, prioritizing +3V3 rails,
   then GND stitching vias, then signals.
2. Or split into multiple Freerouting runs with net-class filters so each
   pass routes a smaller subset and avoids the NPE trigger.
3. Or investigate the specific degenerate geometry triggering the NPE.
